# Forsprang Android app (Trusted Web Activity)

This folder is the Android wrapper for Forsprang (Min side on www.arbeidmatch.no).
It is a Trusted Web Activity generated by Bubblewrap (`@bubblewrap/cli` 1.27.0):
the app opens `https://www.arbeidmatch.no/min-side` full screen in the user's
browser engine. Package `no.arbeidmatch.forsprang`. No push notifications, no
billing, no location delegation, no shortcuts. Falls back to Custom Tabs.

`twa-manifest.json` is the source of truth. Everything else under `app/`,
`gradle/` and the root gradle files is generated from it.

## Toolchain

- JDK 17: `C:\Users\post\android-toolchain\jdk`
- Android SDK: `C:\Users\post\android-toolchain\sdk` (build-tools 36.0.0 used)
- Bubblewrap's own template versions: Android Gradle Plugin 8.9.1, Gradle
  8.11.1 (wrapper), androidbrowserhelper 2.7.4, compile/target SDK 36, minSdk 24.
  AGP 8.9.1 is required by the androidx libraries androidbrowserhelper pulls in,
  and it needs Gradle 8.11.1, which `./gradlew` downloads into `~/.gradle` on
  first run (the separately installed Gradle 8.10.2 is too old and not used).
- Build 1.0.0 (versionCode 1) was produced on 12 Nov 2026 with exactly the
  commands below; copies are in `D:\forsprang-store\app\`.
- `~/.bubblewrap/config.json` holds `jdkPath` and `androidSdkPath` so Bubblewrap
  never downloads its own.

## Signing

- Upload keystore: `C:\Users\post\.forsprang-signing\upload.keystore`, alias `upload`.
- Passwords are sealed (DPAPI, LocalMachine) in
  `C:\Users\post\.forsprang-signing\signing.env.dpapi`. `unseal-signing.ps1`
  prints the `KEY=VALUE` lines to stdout; pipe it, never save or echo it.
- Play App Signing is used: Google holds the app signing key, and this keystore
  is only the **upload key**. If it is lost, Play Console can reset the upload key.

## Rebuild (Git Bash)

Regenerating the project (only after editing `twa-manifest.json`; the icon URLs
and the web manifest URL must be reachable):

```bash
cd forsprang-android
npx @bubblewrap/cli@1.27.0 update --skipVersionUpgrade
```

Build and sign (equivalent of `bubblewrap build`, which in 1.27 wants build-tools
36.1.0 and an SDK with a `bin` folder; this uses the installed build-tools 36.0.0):

```bash
cd forsprang-android
export JAVA_HOME='C:\Users\post\android-toolchain\jdk'
export ANDROID_HOME='C:\Users\post\android-toolchain\sdk'
BT="$ANDROID_HOME/build-tools/36.0.0"
./gradlew --no-daemon bundleRelease assembleRelease

(
  while IFS='=' read -r k v; do
    case "$k" in
      FORSPRANG_KEYSTORE_PASSWORD) export BUBBLEWRAP_KEYSTORE_PASSWORD="$v" ;;
      FORSPRANG_KEY_PASSWORD) export BUBBLEWRAP_KEY_PASSWORD="$v" ;;
    esac
  done < <(powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./unseal-signing.ps1 | tr -d '\r')

  "$BT/zipalign.exe" -v -c -p 4 app/build/outputs/apk/release/app-release-unsigned.apk >/dev/null
  cp app/build/outputs/apk/release/app-release-unsigned.apk app-release-unsigned-aligned.apk
  "$BT/apksigner.bat" sign --ks 'C:\Users\post\.forsprang-signing\upload.keystore' --ks-key-alias upload \
    --ks-pass env:BUBBLEWRAP_KEYSTORE_PASSWORD --key-pass env:BUBBLEWRAP_KEY_PASSWORD \
    --out app-release-signed.apk app-release-unsigned-aligned.apk
  "$JAVA_HOME/bin/jarsigner" -sigalg SHA256withRSA -digestalg SHA-256 \
    -keystore 'C:\Users\post\.forsprang-signing\upload.keystore' \
    -storepass:env BUBBLEWRAP_KEYSTORE_PASSWORD -keypass:env BUBBLEWRAP_KEY_PASSWORD \
    -signedjar app-release-bundle.aab app/build/outputs/bundle/release/app-release.aab upload
)
```

Outputs: `app-release-bundle.aab` (upload to Play) and `app-release-signed.apk`
(sideload / testing). Before the next release, raise `appVersionCode` and
`appVersion` in `twa-manifest.json` and regenerate.

## Digital Asset Links

The site must serve `https://www.arbeidmatch.no/.well-known/assetlinks.json`
with the package name and the SHA-256 fingerprints of both the upload key and
the Play App Signing key (from Play Console, App integrity), otherwise the app
shows a browser URL bar instead of running full screen.
